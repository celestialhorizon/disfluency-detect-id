# SIFAT DATA (baca sebelum memakai angka apa pun dari korpus ini):
# Kalimat di berkas ini DITULIS TANGAN oleh peneliti sebagai contoh
# fenomena kebahasaan, BUKAN transkrip rekaman nyata. Fungsinya adalah
# menguji kebenaran pipeline (unit test tingkat sistem) dan mengunci
# pedoman anotasi sebelum anotasi korpus sungguhan dimulai. Metrik yang
# dihasilkan dari korpus ini TIDAK BOLEH dilaporkan sebagai temuan
# empiris; ia hanya membuktikan bahwa perangkatnya berjalan.
#
# FORMAT
#   kata/TAG   -> token beranotasi
#   kata       -> token fluen (label O tersirat)
#   # ...      -> komentar
#
# TAGSET
#   FP   filled pause              eee, emm, hmm, anu
#   DM   discourse marker filler   kayak, gitu, nah, apa ya
#   REP  repetition disfluency     salinan berlebih yang dibuang
#   RPR  reparandum + editing term materi batal yang diralat
#   PW   partial word              fragmen kata terpotong (pe-)
#   O    fluen (default)
#
# PEDOMAN ANOTASI (keputusan yang dikunci agar anotasi konsisten)
#   1. Pada repetisi, yang ditandai REP adalah salinan AWAL; salinan
#      terakhir dipertahankan karena itulah yang diteruskan penutur.
#   2. Pada ralat, reparandum DAN penanda ralat (eh, maaf, bukan,
#      maksudnya) sama-sama ditandai RPR; bagian perbaikannya O.
#   3. "jadi" di awal giliran bicara = DM (pembuka kosong makna);
#      "jadi" di tengah setelah sebab yang disebut = O (konjungsi).
#   4. "ya" sebagai jawaban afirmatif = O; "ya" penutup klausa = DM.
#   5. "apa" sebagai kata tanya = O; "apa" saat mencari kata = DM.
#   6. Reduplikasi gramatikal SELALU O, baik ditulis bertanda hubung
#      (anak-anak) maupun terpisah (anak anak). Inilah kelas negatif
#      terpenting: kesalahan memotongnya merusak makna kalimat.
